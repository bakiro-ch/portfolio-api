# 📋 Requirements (MVP)

## ✅ Functional
- عرض المشاريع المنشورة للعامة (بيانات ديناميكية من DB).
- إنشاء/تعديل/حذف المشاريع (Admin فقط، مؤجل حماية الـ Endpoint للأسبوع 2).
- التحقق الصارم من المدخلات (العنوان مطلوب ≥3 أحرف، الحالة محددة مسبقاً).
- الرد بخطأ موحد `{statusCode, message, error}` عند فشل التحقق أو الخطأ الداخلي.
- عرض المهارات، الشهادات، اللغات، وسنوات الخبرة (كبيانات ثابتة/ديناميكية بسيطة).
- فلترة وبحث أساسي في قائمة المشاريع.

## ⚡ Non-Functional
- الأمان: DTO Validation إلزامي، Secrets معزولة في `.env`، CORS مضبوط.
- الأداء: Pagination + Filtering + Indexes على حقول البحث، استجابة < 200ms.
- Timeout: رفض الطلبات التي تتجاوز `10s` وإعادة `408/504` مع رسالة واضحة.
- DX: Swagger تلقائي، أخطاء موحدة، هيكل `Modules` مستقل، English Commits.
- البساطة: واجهة عامة تدعم الوضع الفاتح/الداكن (Frontend فقط، لا يؤثر على الـ API).
