# 📄 Project Vision: Dynamic Portfolio + Admin CMS

## 🎯 الفكرة
منصة بورتفوليو ديناميكية مع لوحة تحكم خفيفة، تتيح لي إدارة المشاريع، المهارات، ورسائل التواصل دون تعديل الكود أو إعادة النشر.

## 👥 المستخدم الأساسي
مسؤولو التوظيف، لجان المنح، وعملاء الفري لانسر المحتملون.

## ⚡ المشكلة
- البورتفوليو الثابت يتطلب تعديل كود ونشر لكل تحديث بسيط.
- مشاريع الدورات لا تثبت القدرة على بناء نظام آمن، موثق، وقابل للصيانة.

## 💎 القيمة الأساسية
- إثبات كفاءة Full-Stack عبر نظام إنتاجي (Auth, CRUD, Validation, API Docs, Docker).
- أساس قابل لإعادة الاستخدام لمشاريع تجارية قادمة (مثل DzStore).

## 🚫 خارج النطاق الآن
- مدونة، دردشة مباشرة، دفع إلكتروني، أو تعدد الأدوار (Admin فقط في MVP).
